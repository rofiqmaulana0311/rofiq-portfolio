# p02-laut-coffee

Taruh gambar proyek ini di folder ini, berurutan:

```
01.jpg   <- gambar utama (dipakai juga di intro & pratinjau hover)
02.jpg
03.jpg
...
```

Lalu di `content.js`, ubah `shots:W("p02-laut-coffee",0)` menjadi jumlah gambarnya, mis. `shots:W("p02-laut-coffee",6)`.

- Format: JPG (atau ganti ekstensi: `W("p02-laut-coffee",6,"webp")`)
- Ukuran ideal: lebar 2000 px, rasio 16:10 (lebar) atau 4:5 (potret)
- Nama folder boleh diganti, asal sama dengan yang ditulis di `content.js`
